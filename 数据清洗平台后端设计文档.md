# 数据清洗平台后端设计文档

## 1. 项目概述

### 1.1 项目背景
数据清洗平台是一个专注于数据源连接、清洗任务配置和执行的轻量级平台。平台支持多种数据源连接，提供简单的清洗规则配置，并使用Apache Flink执行数据清洗任务。

### 1.2 核心功能
- **数据源配置&连接**：支持连接ES、Kafka、MySQL等常用数据源
- **清洗任务配置&提交运行**：配置清洗任务并提交到Flink执行
- **简单清洗规则配置**：支持基础的字段映射、数据转换、过滤等规则

#### 4.1.4 数据源工厂和注册机制

```java
// 数据源连接器工厂
@Component
public class DataSourceConnectorFactory {
    
    private final Map<DataSourceType, DataSourceConnector> connectors = new ConcurrentHashMap<>();
    
    /**
     * 注册数据源连接器
     */
    public void registerConnector(DataSourceConnector connector) {
        connectors.put(connector.getSupportedType(), connector);
    }
    
    /**
     * 获取数据源连接器
     */
    public DataSourceConnector getConnector(DataSourceType type) {
        DataSourceConnector connector = connectors.get(type);
        if (connector == null) {
            throw new UnsupportedDataSourceException("不支持的数据源类型: " + type);
        }
        return connector;
    }
    
    /**
     * 获取所有支持的数据源类型
     */
    public Set<DataSourceType> getSupportedTypes() {
        return connectors.keySet();
    }
    
    /**
     * 自动注册所有连接器
     */
    @PostConstruct
    public void autoRegisterConnectors() {
        // 通过Spring容器自动发现并注册所有DataSourceConnector实现
        ApplicationContext context = ApplicationContextHolder.getContext();
        Map<String, DataSourceConnector> beans = context.getBeansOfType(DataSourceConnector.class);
        beans.values().forEach(this::registerConnector);
    }
}

// 数据源连接器注册注解
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Component
public @interface DataSourceConnectorComponent {
    DataSourceType value();
}
```

#### 4.1.5 具体连接器实现示例

```java
// MySQL连接器实现
@DataSourceConnectorComponent(DataSourceType.MYSQL)
public class MySQLConnector implements DataSourceConnector {
    
    private final Map<String, HikariDataSource> connectionPools = new ConcurrentHashMap<>();
    
    @Override
    public DataSourceType getSupportedType() {
        return DataSourceType.MYSQL;
    }
    
    @Override
    public ConnectionResult testConnection(DataSourceConfig config) {
        MySQLConfig mysqlConfig = (MySQLConfig) config;
        long startTime = System.currentTimeMillis();
        
        try {
            mysqlConfig.validate();
            
            // 创建测试连接
            HikariConfig hikariConfig = createHikariConfig(mysqlConfig);
            hikariConfig.setMaximumPoolSize(1);
            hikariConfig.setConnectionTimeout(mysqlConfig.getConnectTimeout());
            
            try (HikariDataSource dataSource = new HikariDataSource(hikariConfig);
                 Connection connection = dataSource.getConnection()) {
                
                // 执行简单查询测试
                try (PreparedStatement stmt = connection.prepareStatement("SELECT 1");
                     ResultSet rs = stmt.executeQuery()) {
                    
                    long responseTime = System.currentTimeMillis() - startTime;
                    
                    Map<String, Object> metadata = new HashMap<>();
                    metadata.put("version", connection.getMetaData().getDatabaseProductVersion());
                    metadata.put("driverVersion", connection.getMetaData().getDriverVersion());
                    
                    return new ConnectionResult(true, "连接成功", responseTime, metadata);
                }
            }
        } catch (Exception e) {
            long responseTime = System.currentTimeMillis() - startTime;
            return new ConnectionResult(false, "连接失败: " + e.getMessage(), responseTime, null);
        }
    }
    
    @Override
    public QueryResult executeQuery(DataSourceConfig config, QueryRequest request) {
        MySQLConfig mysqlConfig = (MySQLConfig) config;
        
        try (Connection connection = getConnection(mysqlConfig);
             PreparedStatement stmt = connection.prepareStatement(request.getSql())) {
            
            // 设置查询超时
            stmt.setQueryTimeout(request.getTimeout() / 1000);
            
            // 设置参数
            if (request.getParameters() != null) {
                int index = 1;
                for (Object param : request.getParameters().values()) {
                    stmt.setObject(index++, param);
                }
            }
            
            try (ResultSet rs = stmt.executeQuery()) {
                return buildQueryResult(rs, request.getPageSize());
            }
            
        } catch (SQLException e) {
            throw new DataSourceException("查询执行失败", e);
        }
    }
    
    @Override
    public WriteResult writeData(DataSourceConfig config, WriteRequest request) {
        MySQLConfig mysqlConfig = (MySQLConfig) config;
        long startTime = System.currentTimeMillis();
        
        try (Connection connection = getConnection(mysqlConfig)) {
            connection.setAutoCommit(false);
            
            String sql = buildInsertSQL(request);
            
            try (PreparedStatement stmt = connection.prepareStatement(sql)) {
                stmt.setQueryTimeout(request.getTimeout() / 1000);
                
                int affectedRows = 0;
                for (Map<String, Object> row : request.getData()) {
                    setStatementParameters(stmt, row);
                    affectedRows += stmt.executeUpdate();
                }
                
                connection.commit();
                
                long executionTime = System.currentTimeMillis() - startTime;
                return new WriteResult(true, affectedRows, "写入成功", executionTime, null);
                
            } catch (SQLException e) {
                connection.rollback();
                throw e;
            }
            
        } catch (SQLException e) {
            long executionTime = System.currentTimeMillis() - startTime;
            return new WriteResult(false, 0, "写入失败: " + e.getMessage(), 
                                 executionTime, Arrays.asList(e.getMessage()));
        }
    }
    
    // 私有辅助方法
    private HikariConfig createHikariConfig(MySQLConfig config) {
        HikariConfig hikariConfig = new HikariConfig();
        hikariConfig.setJdbcUrl(config.getConnectionString());
        hikariConfig.setUsername(config.getUsername());
        hikariConfig.setPassword(config.getPassword());
        hikariConfig.setDriverClassName("com.mysql.cj.jdbc.Driver");
        hikariConfig.setMaximumPoolSize(10);
        hikariConfig.setMinimumIdle(2);
        hikariConfig.setConnectionTimeout(config.getConnectTimeout());
        hikariConfig.setIdleTimeout(600000);
        hikariConfig.setMaxLifetime(1800000);
        return hikariConfig;
    }
    
    private Connection getConnection(MySQLConfig config) throws SQLException {
        String key = config.getConnectionString();
        HikariDataSource dataSource = connectionPools.computeIfAbsent(key, 
            k -> new HikariDataSource(createHikariConfig(config)));
        return dataSource.getConnection();
    }
}

// ClickHouse连接器实现
@DataSourceConnectorComponent(DataSourceType.CLICKHOUSE)
public class ClickHouseConnector implements DataSourceConnector {
    
    private final Map<String, HikariDataSource> connectionPools = new ConcurrentHashMap<>();
    
    @Override
    public DataSourceType getSupportedType() {
        return DataSourceType.CLICKHOUSE;
    }
    
    @Override
    public ConnectionResult testConnection(DataSourceConfig config) {
        ClickHouseConfig chConfig = (ClickHouseConfig) config;
        long startTime = System.currentTimeMillis();
        
        try {
            chConfig.validate();
            
            try (Connection connection = getConnection(chConfig);
                 PreparedStatement stmt = connection.prepareStatement("SELECT 1");
                 ResultSet rs = stmt.executeQuery()) {
                
                long responseTime = System.currentTimeMillis() - startTime;
                
                Map<String, Object> metadata = new HashMap<>();
                metadata.put("version", connection.getMetaData().getDatabaseProductVersion());
                
                return new ConnectionResult(true, "连接成功", responseTime, metadata);
            }
        } catch (Exception e) {
            long responseTime = System.currentTimeMillis() - startTime;
            return new ConnectionResult(false, "连接失败: " + e.getMessage(), responseTime, null);
        }
    }
    
    // ClickHouse特有的批量插入优化
    @Override
    public WriteResult batchWriteData(DataSourceConfig config, BatchWriteRequest request) {
        ClickHouseConfig chConfig = (ClickHouseConfig) config;
        long startTime = System.currentTimeMillis();
        
        try (Connection connection = getConnection(chConfig)) {
            connection.setAutoCommit(false);
            
            String sql = buildInsertSQL(request.getDatabase(), request.getTable(), 
                                      request.getBatches().get(0).get(0).keySet());
            
            try (PreparedStatement stmt = connection.prepareStatement(sql)) {
                stmt.setQueryTimeout(request.getTimeout() / 1000);
                
                long totalAffectedRows = 0;
                
                for (List<Map<String, Object>> batch : request.getBatches()) {
                    for (Map<String, Object> row : batch) {
                        setStatementParameters(stmt, row);
                        stmt.addBatch();
                    }
                    
                    int[] results = stmt.executeBatch();
                    totalAffectedRows += Arrays.stream(results).sum();
                    stmt.clearBatch();
                }
                
                connection.commit();
                
                long executionTime = System.currentTimeMillis() - startTime;
                return new WriteResult(true, totalAffectedRows, "批量写入成功", executionTime, null);
                
            } catch (SQLException e) {
                connection.rollback();
                throw e;
            }
            
        } catch (SQLException e) {
            long executionTime = System.currentTimeMillis() - startTime;
            return new WriteResult(false, 0, "批量写入失败: " + e.getMessage(), 
                                 executionTime, Arrays.asList(e.getMessage()));
        }
    }
    
    private Connection getConnection(ClickHouseConfig config) throws SQLException {
        String key = config.getConnectionString();
        HikariDataSource dataSource = connectionPools.computeIfAbsent(key, 
            k -> new HikariDataSource(createHikariConfig(config)));
        return dataSource.getConnection();
    }
    
    private HikariConfig createHikariConfig(ClickHouseConfig config) {
        HikariConfig hikariConfig = new HikariConfig();
        hikariConfig.setJdbcUrl(config.getConnectionString());
        hikariConfig.setUsername(config.getUsername());
        hikariConfig.setPassword(config.getPassword());
        hikariConfig.setDriverClassName("com.clickhouse.jdbc.ClickHouseDriver");
        hikariConfig.setMaximumPoolSize(20); // ClickHouse支持更高并发
        hikariConfig.setMinimumIdle(5);
        hikariConfig.setConnectionTimeout(config.getConnectTimeout());
        
        // ClickHouse特有配置
        hikariConfig.addDataSourceProperty("compress", config.getCompress());
        if (config.getProfile() != null) {
            hikariConfig.addDataSourceProperty("profile", config.getProfile());
        }

// Kafka连接器实现
@DataSourceConnectorComponent(DataSourceType.KAFKA)
public class KafkaConnector implements DataSourceConnector {
    
    private final Map<String, KafkaProducer<String, String>> producers = new ConcurrentHashMap<>();
    private final Map<String, KafkaConsumer<String, String>> consumers = new ConcurrentHashMap<>();
    
    @Override
    public DataSourceType getSupportedType() {
        return DataSourceType.KAFKA;
    }
    
    @Override
    public ConnectionResult testConnection(DataSourceConfig config) {
        KafkaConfig kafkaConfig = (KafkaConfig) config;
        long startTime = System.currentTimeMillis();
        
        try {
            kafkaConfig.validate();
            
            Properties props = createProducerProperties(kafkaConfig);
            
            try (KafkaProducer<String, String> producer = new KafkaProducer<>(props)) {
                // 获取集群元数据来测试连接
                producer.partitionsFor("__consumer_offsets"); // 使用内部topic测试
                
                long responseTime = System.currentTimeMillis() - startTime;
                
                Map<String, Object> metadata = new HashMap<>();
                metadata.put("bootstrapServers", kafkaConfig.getBootstrapServers());
                
                return new ConnectionResult(true, "连接成功", responseTime, metadata);
            }
        } catch (Exception e) {
            long responseTime = System.currentTimeMillis() - startTime;
            return new ConnectionResult(false, "连接失败: " + e.getMessage(), responseTime, null);
        }
    }
    
    @Override
    public List<TableInfo> getTables(DataSourceConfig config, String database) {
        KafkaConfig kafkaConfig = (KafkaConfig) config;
        List<TableInfo> topics = new ArrayList<>();
        
        Properties props = createConsumerProperties(kafkaConfig);
        
        try (KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props)) {
            Map<String, List<PartitionInfo>> topicsInfo = consumer.listTopics();
            
            for (Map.Entry<String, List<PartitionInfo>> entry : topicsInfo.entrySet()) {
                String topicName = entry.getKey();
                if (!topicName.startsWith("__")) { // 过滤内部topic
                    TableInfo topic = new TableInfo();
                    topic.setName(topicName);
                    topic.setComment("Kafka Topic - " + entry.getValue().size() + " partitions");
                    topics.add(topic);
                }
            }
        }
        
        return topics;
    }
    
    @Override
    public QueryResult executeQuery(DataSourceConfig config, QueryRequest request) {
        KafkaConfig kafkaConfig = (KafkaConfig) config;
        
        Properties props = createConsumerProperties(kafkaConfig);
        props.put(ConsumerConfig.GROUP_ID_CONFIG, "data-cleaning-query-" + System.currentTimeMillis());
        props.put(ConsumerConfig.AUTO_OFFSET_RESET_CONFIG, "earliest");
        
        try (KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props)) {
            TopicPartition partition = new TopicPartition(request.getTable(), 0);
            consumer.assign(Arrays.asList(partition));
            
            // 从指定位置开始消费
            if (request.getCursor() != null) {
                consumer.seek(partition, Long.parseLong(request.getCursor()));
            } else {
                consumer.seekToBeginning(Arrays.asList(partition));
            }
            
            List<Map<String, Object>> data = new ArrayList<>();
            ConsumerRecords<String, String> records = consumer.poll(Duration.ofMillis(request.getTimeout()));
            
            for (ConsumerRecord<String, String> record : records) {
                Map<String, Object> row = new HashMap<>();
                row.put("offset", record.offset());
                row.put("partition", record.partition());
                row.put("timestamp", record.timestamp());
                row.put("key", record.key());
                row.put("value", record.value());
                data.add(row);
                
                if (data.size() >= request.getPageSize()) {
                    break;
                }
            }
            
            QueryResult result = new QueryResult();
            result.setData(data);
            result.setTotalCount(data.size());
            result.setHasMore(data.size() >= request.getPageSize());
            
            if (!data.isEmpty()) {
                long lastOffset = (Long) data.get(data.size() - 1).get("offset");
                result.setNextCursor(String.valueOf(lastOffset + 1));
            }
            
            return result;
        }
    }
    
    @Override
    public WriteResult writeData(DataSourceConfig config, WriteRequest request) {
        KafkaConfig kafkaConfig = (KafkaConfig) config;
        long startTime = System.currentTimeMillis();
        
        try {
            KafkaProducer<String, String> producer = getProducer(kafkaConfig);
            
            List<Future<RecordMetadata>> futures = new ArrayList<>();
            
            for (Map<String, Object> row : request.getData()) {
                String key = row.containsKey("key") ? row.get("key").toString() : null;
                String value = row.containsKey("value") ? row.get("value").toString() : 
                              objectMapper.writeValueAsString(row);
                
                ProducerRecord<String, String> record = new ProducerRecord<>(request.getTable(), key, value);
                futures.add(producer.send(record));
            }
            
            // 等待所有消息发送完成
            long successCount = 0;
            List<String> errors = new ArrayList<>();
            
            for (Future<RecordMetadata> future : futures) {
                try {
                    future.get(request.getTimeout(), TimeUnit.MILLISECONDS);
                    successCount++;
                } catch (Exception e) {
                    errors.add(e.getMessage());
                }
            }
            
            long executionTime = System.currentTimeMillis() - startTime;
            
            if (errors.isEmpty()) {
                return new WriteResult(true, successCount, "写入成功", executionTime, null);
            } else {
                return new WriteResult(false, successCount, "部分写入失败", executionTime, errors);
            }
            
        } catch (Exception e) {
            long executionTime = System.currentTimeMillis() - startTime;
            return new WriteResult(false, 0, "写入失败: " + e.getMessage(), 
                                 executionTime, Arrays.asList(e.getMessage()));
        }
    }
    
    private Properties createProducerProperties(KafkaConfig config) {
        Properties props = new Properties();
        props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, config.getBootstrapServers());
        props.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, StringSerializer.class.getName());
        props.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, StringSerializer.class.getName());
        props.put(ProducerConfig.ACKS_CONFIG, "all");
        props.put(ProducerConfig.RETRIES_CONFIG, 3);
        
        // 添加安全配置
        if (!"PLAINTEXT".equals(config.getSecurityProtocol())) {
            props.put(CommonClientConfigs.SECURITY_PROTOCOL_CONFIG, config.getSecurityProtocol());
            if (config.getSaslMechanism() != null) {
                props.put(SaslConfigs.SASL_MECHANISM, config.getSaslMechanism());
            }
            if (config.getSaslJaasConfig() != null) {
                props.put(SaslConfigs.SASL_JAAS_CONFIG, config.getSaslJaasConfig());
            }
        }
        
        // 添加额外配置
        if (config.getAdditionalProperties() != null) {
            props.putAll(config.getAdditionalProperties());
        }
        
        return props;
    }
    
    private Properties createConsumerProperties(KafkaConfig config) {
        Properties props = new Properties();
        props.put(ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG, config.getBootstrapServers());
        props.put(ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG, StringDeserializer.class.getName());
        props.put(ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG, StringDeserializer.class.getName());
        props.put(ConsumerConfig.ENABLE_AUTO_COMMIT_CONFIG, false);
        
        // 添加安全配置
        if (!"PLAINTEXT".equals(config.getSecurityProtocol())) {
            props.put(CommonClientConfigs.SECURITY_PROTOCOL_CONFIG, config.getSecurityProtocol());
            if (config.getSaslMechanism() != null) {
                props.put(SaslConfigs.SASL_MECHANISM, config.getSaslMechanism());
            }
            if (config.getSaslJaasConfig() != null) {
                props.put(SaslConfigs.SASL_JAAS_CONFIG, config.getSaslJaasConfig());
            }
        }
        
        return props;
    }
    
    private KafkaProducer<String, String> getProducer(KafkaConfig config) {
        String key = config.getBootstrapServers();
        return producers.computeIfAbsent(key, k -> new KafkaProducer<>(createProducerProperties(config)));
    }
```

## 12. 数据源模块设计总结

### 12.1 设计亮点

#### 12.1.1 可扩展架构
- **策略模式**：每种数据源类型都有独立的连接器实现，便于扩展新的数据源类型
- **工厂模式**：统一的连接器工厂管理，支持动态注册新的数据源连接器
- **配置抽象**：通过抽象基类和JSON多态序列化，支持不同数据源的个性化配置

#### 12.1.2 安全性设计
- **敏感信息加密**：数据库中存储的密码等敏感信息进行加密处理
- **连接池管理**：使用HikariCP等成熟连接池，避免连接泄露
- **参数验证**：完善的输入验证和SQL注入防护

#### 12.1.3 高性能优化
- **连接复用**：智能连接池管理，减少连接开销
- **批量操作**：支持批量写入，提高数据处理效率
- **异步处理**：支持异步查询和写入操作

#### 12.1.4 监控和运维
- **健康检查**：定时检查数据源连接状态
- **操作日志**：完整记录所有数据源操作，便于问题排查
- **连接历史**：保存连接测试历史，便于分析连接稳定性

### 12.2 支持的数据源类型

### 12.4 扩展指南

#### 12.4.1 添加新数据源类型
1. **创建配置类**：继承`DataSourceConfig`，实现具体配置验证
2. **实现连接器**：实现`DataSourceConnector`接口
3. **添加注解**：使用`@DataSourceConnectorComponent`注解标记
4. **更新枚举**：在`DataSourceType`中添加新类型
5. **配置序列化**：在`DataSourceConfig`的`@JsonSubTypes`中添加映射
